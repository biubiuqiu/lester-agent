LESTER / DESIGN REFERENCE

Lester Design System

把品牌、图标和界面放在同一套规则里。调整风格时，先确定语义角色，再让真实控件跟随变化。

01 / PRINCIPLES

一套规则，少一点决定。Overview

Single source
PRIMITIVE → SEMANTIC

按角色选色

背景、文字、交互、品牌与状态各有职责。一个色值不代替多个语义。

ENTITY → ACTION → STATE

让图形说明对象

类别图标用彩色形体建立识别；操作保持清晰轮廓；成功、风险与等待由真实状态表达。

SOURCE → CSS → HTML

规范跟随实现

本页由相同的 Token 与 SVG 源生成。预览与导出不用重新维护一套颜色。

单一来源，实际复用

Tokens 来自 src/design/tokens.json；本页控件提取自生产 globals.css，图标和 Logo 直接渲染项目 TSX。使用 pnpm design:build 生成，pnpm design:check 检测源与产物是否一致。

覆盖边界

已接入官网、工作区、账户页的基础语义与共享控件；并非所有业务样式都完成迁移。终端、代码高亮、用户 HTML、第三方品牌、旗帜和原生端保持独立。这里的主题切换仅用于比较方案，不会修改应用或保存偏好。对比度展示只检验所列颜色对。
