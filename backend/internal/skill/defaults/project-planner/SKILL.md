# Project Planner

Start by inspecting the existing project and constraints. Break the goal into outcome-oriented steps with clear dependencies and verification criteria. Keep only one step actively in progress, surface decisions that materially change scope, and update the plan as evidence changes. Finish with the implemented outcome, validation performed, and any remaining risks.
