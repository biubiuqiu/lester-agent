## Lester 采用的最小约定

1. **一条标签栏、一个加号。** 文件、成果、技能和可用的已创建 Agent 配置各保留一个工具标签，再次选择会激活已有标签；不固定保留成果/文件栏目，也不再增加平行的工具导航。
2. **终端相互独立。** 最多同时打开四个终端，切换标签或收起工作区保留已连接的 Shell。关闭终端标签、离开会话或退出账号会结束连接。刷新后仅恢复标签布局，用户明确选择连接后才启动新 Shell，不宣称旧进程恢复。
3. **查看状态可信。** 沿用用户、工作区、会话范围的视图存储；保留文件预览/源码方式与阅读位置。文件预览仍有独立的有界列表，只有经过当前会话清单验证的路径才可打开。新文件不抢走已有工具或文件选择。
4. **减少决定，不隐藏必要控制。** 保留类型图标、完整可访问名称、选中态、关闭操作及横向滚动。关闭控件在悬停/键盘聚焦时可见，触屏保持可发现。空面板只提供添加内容的入口。
5. **执行边界不变。** 标签操作不发送任务、不提升权限、不改变草稿、不把文件内容自动注入模型。HTML 继续使用隔离 iframe；原生 iOS/Android 客户端仍隐藏终端与桌面工具。

这次是对现有工作区的整合，不增加代码编辑器、终端会话恢复服务、浏览器控制界面、Pages/Spaces 或会话模式。布局更新不需要新的数据库迁移。

## 实现检查重点

- 终端实例在普通标签切换时不能卸载；隐藏实例不能抢走输入焦点，多个实例的辅助说明 ID 必须唯一。
- 关闭标签与关闭整个面板分开：前者释放相应终端，后者只收起工作区。
- 刷新、切换会话、切换语言及重复内容选择不能隐式执行连接或终端输入。
- 手动工具选择、后台文件到达、专注预览、手机模态面板及嵌套部署确认组合时，仍保留可预期的焦点和返回路径。
- 本笔记不是测试结果。实际生产构建、桌面/手机浏览器回归与终端协议验证，由实现提交独立记录；公开报告不等于 Lester 已复现同一问题。
